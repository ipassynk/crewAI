# Leap0 sandbox toolkit

The Leap0 integration exposes four CrewAI tools backed by a [Leap0](https://leap0.dev) remote sandbox: run Python with optional pip installs, run shell commands, read files, and write text files. Use it when agents should execute code safely in the cloud instead of on the host machine.

## Installation

```bash
uv pip install 'crewai-tools[leap0]'
```

Or with pip:

```bash
pip install "crewai-tools[leap0]"
```

## Requirements

- A Leap0 API key in the environment (`LEAP0_API_KEY`)
- The `leap0` Python SDK (installed via the extra above)

## Usage

Create a `Leap0Client`, create or reference a sandbox, build the toolkit, pass the tools to an agent, run the crew, then call `cleanup()` on the toolkit to delete the sandbox and close the client when you are done.

```python
import os

from crewai import Agent, Crew, Task
from leap0 import Leap0Client

from crewai_tools.tools.leap0_sandbox_tool import create_leap0_sandbox_toolkit


def main() -> None:
    if not os.environ.get("LEAP0_API_KEY"):
        raise SystemExit("Set LEAP0_API_KEY")

    client = Leap0Client()
    sandbox = client.sandboxes.create()
    toolkit, tools = create_leap0_sandbox_toolkit(client, sandbox)

    try:
        developer = Agent(
            role="Python Developer",
            goal="Solve tasks with code in the sandbox",
            backstory="You run code via leap0_execute_code and related tools.",
            tools=tools,
            verbose=True,
        )
        task = Task(
            description="Compute the sum of the integers from 1 to 100 in Python and return the result.",
            agent=developer,
            expected_output="The numeric result.",
        )
        crew = Crew(agents=[developer], tasks=[task], verbose=True)
        print(crew.kickoff())
    finally:
        toolkit.cleanup()
```

### Import paths

You can import the factory from the tools submodule (recommended) or from the `crewai_tools` package barrel when `[leap0]` is installed:

```python
from crewai_tools.tools.leap0_sandbox_tool import create_leap0_sandbox_toolkit
# or
from crewai_tools import create_leap0_sandbox_toolkit
```

## Tools

| Tool name | Purpose |
| :-------- | :------ |
| **leap0_execute_code** | Run Python 3 in the sandbox; optional `libraries_used` installs PyPI packages first |
| **leap0_execute_command** | Run a shell command in the sandbox |
| **leap0_read_file** | Read a file (absolute path under `/`) |
| **leap0_write_file** | Write UTF-8 text to a path (absolute path under `/`) |

## `create_leap0_sandbox_toolkit` arguments

| Argument | Type | Default | Description |
| :------- | :--- | :------ | :---------- |
| **client** | `Leap0Client` | (required) | Authenticated client (reads `LEAP0_API_KEY` by default) |
| **sandbox** | sandbox object or `str` | (required) | Sandbox from `client.sandboxes.create()`, or a sandbox id string (resolved with `client.sandboxes.get`) |
| **default_timeout** | `int` | `1800` | Default process timeout in seconds |
| **delete_sandbox_on_cleanup** | `bool` | `True` | If `True`, `cleanup()` deletes the sandbox |
| **close_client_on_cleanup** | `bool` | `True` | If `True`, `cleanup()` closes the client |

## Environment variables

```bash
LEAP0_API_KEY=your-leap0-api-key
```

## Cleanup

Always call `toolkit.cleanup()` when the crew finishes (or use `try` / `finally`) so sandboxes are not left running. The toolkit is idempotent: repeated `cleanup()` calls are safe.

## Use cases

- **Safe code execution**: Let agents run untrusted or experimental code off the host
- **Dependency isolation**: Install packages in the sandbox without polluting the local environment
- **Data processing**: Read/write files inside the sandbox for ETL-style agent workflows
