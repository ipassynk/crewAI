# Leap0 샌드박스 툴킷

Leap0 연동은 [Leap0](https://leap0.dev) 원격 샌드박스 위에서 동작하는 CrewAI 도구 네 가지를 제공합니다. 선택적 pip 설치와 함께 Python 실행, 셸 명령 실행, 파일 읽기, 텍스트 파일 쓰기가 가능합니다. 에이전트가 호스트가 아닌 클라우드에서 코드를 안전하게 실행해야 할 때 사용하세요.

## 설치

```bash
uv pip install 'crewai-tools[leap0]'
```

또는 pip으로:

```bash
pip install "crewai-tools[leap0]"
```

## 요구 사항

- 환경에 Leap0 API 키(`LEAP0_API_KEY`)
- `leap0` Python SDK(위 extra로 설치됨)

## 사용법

`Leap0Client`를 만들고 샌드박스를 생성하거나 참조한 뒤 툴킷을 구성하고, 도구를 에이전트에 넘기고 크루를 실행합니다. 끝나면 툴킷에서 `cleanup()`을 호출해 샌드박스를 삭제하고 클라이언트를 닫으세요.

```python
import os

from crewai import Agent, Crew, Task
from leap0 import Leap0Client

from crewai_tools.tools.leap0_sandbox_tool import create_leap0_sandbox_toolkit


def main() -> None:
    if not os.environ.get("LEAP0_API_KEY"):
        raise SystemExit("LEAP0_API_KEY를 설정하세요")

    client = Leap0Client()
    sandbox = client.sandboxes.create()
    toolkit, tools = create_leap0_sandbox_toolkit(client, sandbox)

    try:
        developer = Agent(
            role="Python 개발자",
            goal="샌드박스 안에서 코드로 작업을 해결합니다",
            backstory="leap0_execute_code 및 관련 도구로 코드를 실행합니다.",
            tools=tools,
            verbose=True,
        )
        task = Task(
            description="Python으로 1부터 100까지 정수의 합을 구하고 결과를 반환하세요.",
            agent=developer,
            expected_output="숫자 결과.",
        )
        crew = Crew(agents=[developer], tasks=[task], verbose=True)
        print(crew.kickoff())
    finally:
        toolkit.cleanup()
```

### 가져오기 경로

팩토리 함수는 도구 하위 모듈에서 가져오는 것을 권장하며, `[leap0]`가 설치된 경우 `crewai_tools` 패키지 루트에서도 가져올 수 있습니다.

```python
from crewai_tools.tools.leap0_sandbox_tool import create_leap0_sandbox_toolkit
# 또는
from crewai_tools import create_leap0_sandbox_toolkit
```

## 도구

| 도구 이름 | 용도 |
| :-------- | :--- |
| **leap0_execute_code** | 샌드박스에서 Python 3 실행. 선택 필드 `libraries_used`로 먼저 PyPI 패키지 설치 |
| **leap0_execute_command** | 샌드박스에서 셸 명령 실행 |
| **leap0_read_file** | 파일 읽기(`/` 아래 절대 경로) |
| **leap0_write_file** | 경로에 UTF-8 텍스트 쓰기(`/` 아래 절대 경로) |

## `create_leap0_sandbox_toolkit` 인수

| 인수 | 유형 | 기본값 | 설명 |
| :------- | :--- | :------ | :--- |
| **client** | `Leap0Client` | (필수) | 인증된 클라이언트(기본적으로 `LEAP0_API_KEY` 사용) |
| **sandbox** | 샌드박스 객체 또는 `str` | (필수) | `client.sandboxes.create()` 결과이거나, 샌드박스 ID 문자열(`client.sandboxes.get`으로 조회) |
| **default_timeout** | `int` | `1800` | 프로세스 기본 타임아웃(초) |
| **delete_sandbox_on_cleanup** | `bool` | `True` | `True`이면 `cleanup()` 시 샌드박스 삭제 |
| **close_client_on_cleanup** | `bool` | `True` | `True`이면 `cleanup()` 시 클라이언트 종료 |

## 환경 변수

```bash
LEAP0_API_KEY=your-leap0-api-key
```

## 정리

크루 실행이 끝난 뒤에는 항상 `toolkit.cleanup()`을 호출하세요(`try` / `finally` 사용 권장). 그래야 샌드박스가 남지 않습니다. 툴킷은 **멱등**입니다. `cleanup()`을 여러 번 호출해도 안전합니다.

## 사용 사례

- **안전한 코드 실행**: 검증되지 않았거나 실험적인 코드를 호스트 밖에서 실행
- **의존성 격리**: 로컬 환경을 오염시키지 않고 샌드박스에만 패키지 설치
- **데이터 처리**: ETL 스타일 에이전트 워크플로를 위해 샌드박스 내부에서 파일 읽기/쓰기
